# BERT Sentiment Analysis Project 🚀

A sentiment analysis project using **BERT**.  
The model was fine-tuned on the IMDB Movie Reviews dataset to classify text as positive or negative.

---

## 📌 Features
- Fine-tuned **BERT base** for binary sentiment classification  
- Returns **prediction + confidence score**  
- Lightweight and easy to use for text analysis  

---


## 🧠 Model Details
- **BERT Base Uncased**  
- Fine-tuned for **binary sentiment classification**  
- Training done on **Google Colab (GPU)**  
- Dataset: **IMDB Movie Reviews**  
  - Link: [IMDB Dataset](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)
